# Лекция 6. Стратегия "Разделяй и властвуй"

## Что это вообще такое
Divide and Conquer это стратегия:
1) Divide: разбить задачу на подзадачи
2) Conquer: решить подзадачи
3) Combine: собрать общий ответ

## Где встречается
- Binary Search (поиск за O(log n))
- Quicksort / Mergesort (сортировки)
- Многие задачи "найди ответ по условию" через поиск по ответу (binary search on answer)

## На что смотреть в решении
- Подзадачи должны быть существенно меньше исходной задачи
- Должен быть чёткий base case
- Комбинация результатов должна быть понятной и корректной
- Обязательно анализ сложности: сколько уровней разбиения и сколько работы на уровне


# Лекция 9. Хеш-таблицы, коллизии и кеширование

В этой лекции мы изучаем структуру данных **Hash Table** и её применение в реальных системах.

Hash Table позволяет выполнять поиск данных очень быстро — в среднем за **O(1)**.

---

## Основные темы лекции

- Hash Function
- Hash Table
- Коллизии (Collisions)
- Быстродействие поиска
- Использование hash tables в реальных системах
- Кеширование (Cache)

---

### Пример кеширования

Файл:

9_browserCacheDemo.html

Показывает как работает кеш в браузере через **localStorage**.

Идея кеша:

key → value

Например:

URL → response data

---

## Как работает кеш в примере

Первый запрос:

server → данные сохраняются в localStorage

Повторный запрос:

cache → данные берутся из localStorage

---

## Что показать в DevTools

1. Application → Local Storage
2. ключ

/api/products

3. Console:

localStorage.getItem('/api/products')

---

## Связь с Hash Tables

Кеш использует ту же идею:

key → value

Пример:

URL → JSON data

Это позволяет быстро находить данные без повторного запроса к серверу.
